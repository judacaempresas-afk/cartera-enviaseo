# Dashboard de Cartera Vencida — Enviaseo

Dashboard gerencial interactivo para gestión de cartera vencida.

## Acceso
👉 [Ver Dashboard](https://TU_USUARIO.github.io/cartera-enviaseo/)

## Cómo actualizar los datos cada mes

1. Abre el dashboard desde el link de arriba
2. Ve a la pestaña **"Cargar datos"**
3. Sube el nuevo archivo `.xlsx` de OneDrive
4. Los datos se actualizan inmediatamente en tu sesión

## Estructura del archivo Excel requerida
Las columnas deben ser exactamente:
`Año | Mes | Servicio | Nombres | Documento | Direccion | Telefono | Nro Cuenta | Fecha | Vencimiento | Dias Vcto | Rango | Capital | Interes | Saldo | Pqr | Gestion`

## Acceso restringido
